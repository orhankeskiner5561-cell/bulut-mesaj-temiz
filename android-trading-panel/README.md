# Grafik Pano V1

TradingView çalışma mantığından esinlenen yerel Android grafik arayüzü.

V1 etkileşimleri:
- Mum grafiğini sağa/sola ve yukarı/aşağı sürükleme
- İki parmak pinch zoom
- Sağ fiyat ölçeğinde dikey zoom
- Alt zaman ölçeğinde yatay zoom
- İzleme listesi, üst araç çubuğu, sol çizim araçları ve alt panel
